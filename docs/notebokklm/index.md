# NoteBookLM 使用总结

## 1、生成儿童绘本或者PPT

* 第一步使用Gemini生成prompt

```
根据列那狐故事帮我完成一个小学生作业PPT，来讲述这个故事
```

 ```
 这是一个非常有趣的主题！《列那狐的故事》（Reynard the Fox）是一部中世纪的经典动物寓言，主角列那狐聪明、狡猾，经常捉弄其他比他强壮的动物。
 
 针对小学生群体，PPT的设计需要注意以下几点：
 1.  **故事选择**：列那狐有些故事比较黑暗或成人化，我们要选择**有趣、简单、强调智慧战胜蛮力**的段落。最经典且适合孩子的是“**列那狐教狼钓鱼**”的故事。
 2.  **语言风格**：简单生动，富有童趣，避免生僻字。
 3.  **视觉效果**：图片要多，文字要少。每一页最好都配有卡通插图。
 4.  **教育意义**：结尾要有一个简单易懂的道理。
 
 下面是一个为你设计的小学生作业PPT大纲，共约10-12页。你可以根据这个框架去寻找图片和制作。
 
 ---
 
 ### PPT整体风格建议
 * **背景**：森林、卡通风格。
 * **字体**：可爱的卡通字体，字号要大。
 * **配图**：这是关键！一定要找可爱的动物卡通图（狐狸、狼、狮子等）。
 
 ---
 
 ### PPT内容大纲
 
 #### 第1页：封面页
 * **标题**：《机智的列那狐》
 * **副标题**：一个关于聪明和恶作剧的故事
 * **署名**：[你的名字/班级]
 * **配图**：一只看起来非常聪明、嘴角带着坏笑的卡通红狐狸。
 
 #### 第2页：主角介绍——我叫列那！
 * **标题**：认识一下主角
 * **内容**：
     * 大家好，我是**列那**（Reynard）！
     * 我是一只红狐狸。
     * 我的特点：聪明、机智，最喜欢搞点小恶作剧。
     * 我的口头禅：“遇事要动脑筋哦！”
 * **配图**：列那狐指着自己脑袋，眨眼睛的图片。
 
 #### 第3页：配角介绍——我的“笨”邻居们
 * **标题**：森林里的伙伴们
 * **内容**：
     * **伊桑格兰（狼）**：个子大，力气大，但是有点笨，还很贪吃。
     * **诺博尔（狮子）**：森林的国王，威严但有时也会被骗。
     * 今天，我要讲讲我和**狼大哥**的故事。
 * **配图**：一只看起来呆头呆脑的卡通狼，和一只戴皇冠的卡通狮子。
 
 #### 第4页：故事开始——寒冷的冬天
 * **标题**：肚子好饿啊！
 * **内容**：
     * 有一年冬天，天气特别冷，河水都结冰了。
     * 森林里的动物们都找不到吃的。
     * 大灰狼伊桑格兰饿得肚子咕咕叫，正巧碰到了列那狐。
 * **配图**：白雪皑皑的森林背景，大灰狼捂着肚子，一脸苦相。
 
 #### 第5页：列那的“好主意”
 * **标题**：一个钓鱼的秘诀
 * **内容**：
     * 列那狐其实偷到了几条鱼，但他不想分给狼。
     * 他对狼说：“狼大哥，我知道一个钓鱼的好办法！”
     * 狼急忙问：“快告诉我！快告诉我！”
 * **配图**：列那狐手里拿着一条鱼，狡猾地笑着；狼流着口水凑过去听。
 
 #### 第6页：特殊的钓鱼竿
 * **标题**：用尾巴钓鱼？
 * **内容**：
     * 列那把狼带到结冰的河边，在冰上凿了一个洞。
     * 列那说：“把你的长尾巴伸进冰洞里，鱼就会咬住你的尾巴。”
     * “记住，要多等一会儿，尾巴越重，说明钓的鱼越多！”
 * **配图**：狼坐在冰洞边，把尾巴伸进水里的卡通图。
 
 #### 第7页：贪心的狼
 * **标题**：再等一会儿……
 * **内容**：
     * 狼听了列那的话，一动不动地坐在冰上。
     * 天气越来越冷，冰洞的水开始慢慢结冰了。
     * 狼觉得尾巴越来越重，心里想：“哇！肯定钓到大鱼了！我再等一会儿！”
 * **配图**：狼在寒风中瑟瑟发抖，但是脸上露出贪婪的笑容，尾巴周围的冰块在变厚。
 
 #### 第8页：糟糕！动不了了！
 * **标题**：被冻住啦！
 * **内容**：
     * 过了一好久，狼想把尾巴提起来。
     * 哎呀！糟了！
     * 尾巴已经被牢牢地冻在厚厚的冰里，根本拔不出来！
     * 列那狐早就躲在一边偷笑呢。
 * **配图**：狼惊慌失措的表情，用力拔尾巴但纹丝不动；远处树后露出列那狐在偷笑的脑袋。
 
 #### 第9页：结局
 * **标题**：倒霉的狼大哥
 * **内容**：
     * 天亮了，附近的村民出来打水，发现了动不了的狼。
     * 大家拿起棍子打狼，狼好不容易挣断了一截尾巴才逃跑。
     * 可怜的狼，鱼没吃到，还丢了半条尾巴。
 * **配图**：村民拿着扫把追赶狼，狼狼狈逃跑的卡通图（画面要滑稽，不要血腥）。
 
 #### 第10页：我们学到了什么？（总结陈词）
 * **标题**：小故事，大道理
 * **内容**（用醒目的列表展示）：
     1.  **遇事要动脑筋**：像列那狐一样聪明，但不要太坏哦。
     2.  **不要太贪心**：狼因为贪心，想钓好多鱼，结果被冻住了。
     3.  **不要轻信别人**：对于别人的话，我们要自己思考对不对。
 * **配图**：一个思考的灯泡图标，或者一个小朋友在思考的卡通图。
 
 #### 第11页：互动问答（可选，增加趣味性）
 * **标题**：考考你
 * **问题**：
     * 如果你是那只狼，你会相信用尾巴能钓鱼吗？为什么？
 * **配图**：一个大大的问号。
 
 #### 第12页：结束页
 * **标题**：谢谢大家观看！
 * **内容**：希望你们喜欢列那狐的故事。
 * **配图**：列那狐和其他小动物一起挥手再见的可爱图片。
 
 ---
 
 ### 给你的制作小贴士：
 * 如果你找不到合适的图片，可以使用AI绘画工具（如果老师允许），或者在网上搜索关键词如：“狐狸 卡通”、“狼 卡通”、“冬天 森林 卡通”。
 * 讲PPT的时候，声音要生动，模仿狼笨拙的声音和狐狸狡猾的声音，同学们会更喜欢听！
 ```

## 4、读论文

```
1. 原始论文PDF放在左屏幕。

用系统自带或任意分屏工具，比如我用Raycast的Window Management插件。

2. 右边是Gemini 或 NotebookLM。

Gemini排版和提示词遵循更好，虽然有时不如NotebookLM解读的深入，不知道为啥。

3. 用提示词生成解读。

可以用简单提示词，如：用高中生（初中生/小学生/弱智）能懂的话逐句解读这篇论文。

也可以用稍微复杂点的（会包含公式等，指出配图所在页码等）：

你是一位既精通学术研究又擅长把复杂概念讲给中学生听的导师。

请帮我完整读懂这篇论文，我是高中生。

从标题和摘要开始，逐段给我讲解每一部分在说什么，为什么要这么写，和前后段落有什么关系。

遇到专业术语就用日常例子解释清楚，遇到公式就拆开讲每个符号和每步推导的意思，说明这个公式在解决什么问题。

当讲到图表时，明确告诉我这是PDF第几页的哪个图，图里的横纵坐标是什么，曲线或数据代表什么含义，重点要看哪些关键信息，以及这个图是为了证明或说明什么观点。

讲解过程中要指出哪些是论文的核心创新点，哪些是铺垫性的背景知识。

不要跳过任何重要内容，把整篇论文的逻辑线索串起来，让我能理解作者的思路是怎么一步步展开的，以及为什么要这样安排结构。

讲的时候就像老师面对面教学生那样，用完整的段落把每个知识点说透，确保我这个基础薄弱的高中生能真正听懂。

如果我说没理解，请用更简单的方式重新解释，必要时可以降到初中甚至小学的知识水平来类比。
```

## 5、其它

还未实践的一些用法

```
1.创意脑暴

从来源中脑暴10个创新想法：每个想法都要说明概念、对应证据、可行性评分（1-10分）、原型建议。鼓励疯狂类比和“如果……会怎样”的假设，最后按影响力排序。用轻松的对话方式回应，并基于我的回复继续发散。

2.自测与测验生成

根据来源出20道题：10道多选（含解析）、5道简答、5道论文题。标出难易度（简单/中等/困难），提供答案和原文出处，支持“解释为什么我错了”的追问，能跨会话记录我的进度。

3.播客式音频概述

把Audio Overview做成播客形式：两位主持人（一位怀疑派专家，一位热情探险家）围绕来源的关键主题展开辩论。结构：吸睛开场→3段深度对谈（带原文引用）→互相反驳→模拟听众问答→最后给出可执行的3个行动要点。对话要自然、幽默，适当留悬念。

4.发现研究空白

分析来源中的研究空白：(1) 总结学术共识；(2) 找出矛盾或未回答的问题；(3) 提出3个有证据支持的新假设；(4) 推荐后续研究，包括方法和潜在影响。特别关注跨学科连接。

5.快速制作PPT

根据来源制作10页PPT大纲：第1-2页：引言+关键数据/视觉图；第3-7页：核心分析，用项目符号、图表并标注来源；第8-9页：挑战与解决方案；第10页：结论+互动问答提示。每页建议适合的视觉元素（如信息图、流程图），语言精简（每页最多5行）。

6.学术论文深度拆解

用费曼技巧向一个好奇的12岁孩子解释这篇论文的核心概念：用最简单的比喻拆解，找出我理解的漏洞，再用生活例子重新搭建。然后指出材料中的矛盾、偏见和替代解释。最后提出3个现实世界应用场景和1个值得进一步研究的空白。
```
